# The Ledger

> A single-file, offline-first task, habit, and productivity app that runs entirely in your browser.

**No backend. No account. No installation.**

Just open `Ledger.html` and start using it.

All data is stored locally in your browser's `localStorage` and never leaves your machine unless you export it.

## ✨ Features

### 📋 Tasks

* Work & Personal categories
* Daily board grouped by date
* Automatic task carry-over
* Due dates and reminders
* Recurring tasks
* Inline editing and copy
* Automatic URL linking
* Drag-and-drop reordering and date changes
* Delete with Undo
* One-click move to Today

### 🎯 Eisenhower Matrix

* Four priority quadrants
* Quick priority assignment
* Unified Work + Personal matrix view
* Today's due habits appear under **Important / Not Urgent**

### 🔁 Habits

* Recurring habits by specific weekdays or every N days/weeks/months
* Daily check-offs
* Partial/graded completion
* Yearly GitHub-style heatmap
* Completion and missed-day streaks
* Habit data feeds productivity reports

### 📊 Reports

* Daily task and habit goals
* Today's productivity statistics
* Weekly and monthly rollups
* Week-over-week comparison
* 14-day task completion trend
* Habit streaks
* Habits vs. task completion correlation
* Best weekday
* Historical daily reports
* Copyable weekly summary

### ⇅ Sync

* Export all data to timestamped JSON
* Import and restore backups
* Automatic migration of older backup formats
* Easily move data between browsers/devices

### ⧉ Floating Mode

* Pop the Ledger into a floating window using Document Picture-in-Picture
* Minimize to an open-task counter
* Restore the window when needed
* Supported on desktop Chrome and Edge

### 📱 Offline & PWA

* Runs entirely client-side
* No login or backend
* Works offline
* Installable as a PWA
* Responsive layout
* Automatically handles midnight rollover

## 🚀 Getting Started

No build process required.

```text
Open Ledger.html
```

That's it.

## 🔒 Privacy

The Ledger is **local-first**:

* No account
* No backend
* No cloud database
* No required network connection
* Data stays in browser storage
* JSON export/import for backups

**Your data stays yours.**
